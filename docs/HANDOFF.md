1. Прочитати [AGENTS](../AGENTS.md), цей файл, останні записи журналу й прогрес; перевірити Git. Документи є записом минулих перевірок, поточний runtime звірити заново.
2. Визначити нове замовлення користувача. Якщо замовлено події Бенідорма, почати з read-only аудиту джерел для Benidorm та околиць у50km: [SOURCES](SOURCES.md), [архітектура](ARCHITECTURE.md), наявний `services/ingestion`. Не вважати цей рекомендований напрям уже авторизованим до реалізації.

Після перевірки джерела — мінімальний adapter, безпечний імпорт, ідемпотентність, refresh і фактичний radius matching. Якщо даних/прав бракує, записати конкретний блокер.
