# GeoNames data attribution

This application uses geographic data from **GeoNames** (https://www.geonames.org/), licensed under **Creative Commons Attribution 4.0 International**: https://creativecommons.org/licenses/by/4.0/.

Official documentation: https://download.geonames.org/export/dump/readme.txt. Worldwide dump, alternateNamesV2 and countryInfo snapshot SHA256s are recorded in docs/evidence/places/manifest.json.

Changes: selected current populated places and administrative hierarchy; excluded historical/abandoned settlement codes and historical country rows; normalized aliases for search; selected available current Ukrainian/English/Spanish names; linked reviewed existing territory IDs; retained source points without fabricating polygons or event coverage. Generic populated-place feature codes do not establish legal city/village status.

GeoNames does not guarantee completeness, accuracy or timeliness. This is geographical attribution, not an event-data licence. No upstream GeoNames program code was copied.
